## 🚀 Featured Project

### 🛡️ ReAct Agent: Real-time Event Analysis & Collection Tool
*2026 – Present · Team of 2*

A full-stack log analysis platform. I own the backend API, authentication and the desktop analyst app.

- ⚙️ **Ingestion pipeline**: strict Pydantic validation, normalization across sources, buffering in **Redis Streams**, indexing into **OpenSearch**
- 🗄️ **PostgreSQL** schema (users, rules, alerts, agents) with versioned migrations and REST endpoints
- 🔐 **RBAC** with 4 roles (admin, L1 analyst, L2 analyst, engineer); MFA and API-key onboarding in progress
- 🖥️ Cross-platform analyst app built with **Tauri + React + TypeScript**
- 🐳 One-command setup for the whole stack with **Docker Compose**
