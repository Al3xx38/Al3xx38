## Featured Project

### ReAct Agent — Real-time Event Analysis & Collection Tool
*2026 – Present · Team of 2*

A full-stack log analysis platform. I handle the backend API, authentication, and the desktop analyst client.

- **Ingestion pipeline:** strict Pydantic validation, log normalization across sources, buffering in **Redis Streams**, and indexing into **OpenSearch**
- **Database & API:** **PostgreSQL** schema (users, rules, alerts, agents) with versioned migrations and REST endpoints
- **Auth & Security:** **RBAC** with 4 roles (admin, L1 analyst, L2 analyst, engineer); currently working on MFA and API-key onboarding
- **Desktop client:** cross-platform analyst app built with **Tauri + React + TypeScript**
- **Deployment:** one-command local stack setup via **Docker Compose**
